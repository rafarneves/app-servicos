## 📖 Sobre o Projeto

Este projeto é um aplicativo mobile focado em facilitar a contratação de serviços gerais. A ideia central é criar uma ponte direta entre **Empresas** que necessitam de serviços pontuais e **Prestadores de Serviços** qualificados.

O projeto ainda está em fase inicial de ideação e estruturação.

## ✨ Funcionalidades Principais (Proposta)

### 🏢 Para Empresas (Contratantes)
- **Busca de Serviços:** Procure rapidamente pelo tipo de serviço necessário.
- **Oferta Direta:** Envie uma proposta de serviço detalhando a necessidade, valor oferecido (R$) e a expectativa de tempo (horas).
- **Gerenciamento:** Acompanhe o status das contratações e serviços em andamento.

### 👷 Para Prestadores de Serviços
- **Análise de Ofertas:** Receba notificações de ofertas adequadas ao seu perfil.
- **Flexibilidade:** Avalie os detalhes da oferta e tenha total autonomia para **Aceitar** ou **Recusar** o serviço com base no valor e tempo estipulados.
- **Execução:** Fluxo simplificado para acompanhamento do trabalho do início à finalização.

## 💻 Tecnologias

A stack tecnológica principal que guiará o desenvolvimento front-end (mobile) do projeto é:

- **[React Native](https://reactnative.dev/):** Framework para desenvolvimento do app nativo para iOS e Android.
- **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática para garantir um código mais robusto, escalável e com menos bugs.
- **[Tailwind CSS](https://tailwindcss.com/) *(Em estudo)*:** Considerando o uso (possivelmente via `NativeWind`) para estilização ágil e consistente.
- *Frameworks adicionais de roteamento, gerenciamento de estado e backend serão definidos e documentados nas próximas etapas.*
